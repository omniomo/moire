# Latin Modern (web subset)

Subsets of Latin Modern Roman 10 (regular, italic, bold, bold italic) and
Latin Modern Mono 10, used by the Academic theme. Latin, Latin-1 and common
punctuation only; family names carry a "Web" suffix to mark the modification.
